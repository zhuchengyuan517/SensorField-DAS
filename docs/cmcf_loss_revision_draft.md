# CMCF Loss 参数补充草稿

## 给审稿人的回复建议

针对审稿人关于“CMCF Loss 中超参数 λ、α 和 γ 的具体取值及敏感性分析”的意见，修稿稿件中已补充损失函数参数设置与敏感性分析说明。具体而言，焦点损失中的类别平衡系数 `α` 根据训练集类别频次按反比分配并归一化得到，在“背景噪声、车辆行驶、人工作业、挖掘施工”四类上的取值分别为 `0.0471、0.6217、0.1891、0.1421`；聚焦参数 `γ` 取 `2.0`。考虑到实现中协同约束由三部分组成，理论式中的协同系数 `λ` 在程序中进一步细化为 `λ_FAC`、`λ_TAEF` 和 `λ_GCTI`，分别控制共享锚点对齐、任务证据增强和任务关系一致性三项约束。修稿版新增了 5 个随机种子的单因素敏感性实验，对上述协同项权重进行了系统分析，并据此说明最终参数选择的依据。

## 正文可插入到 2.4 节的文字

在参数设置上，焦点分类项中的类别平衡系数 `α_t` 根据训练集类别分布按反比确定。训练集中“背景噪声、车辆行驶、人工作业、挖掘施工”四类样本数分别为 `4129、313、1029、1369`，占比分别为 `60.37%、4.58%、15.04%` 和 `20.01%`。据此采用反频率归一化方式设置类别权重，得到 `α=[0.0471, 0.6217, 0.1891, 0.1421]`。聚焦参数 `γ` 取 `2.0`。此外，为了分别调节不同协同约束分量对训练过程的影响，式(5)中的协同项权重在实现中进一步细化为

`L_CMCF = L_focal + λ_FAC L_FAC + λ_TAEF L_TAEF + λ_GCTI L_GCTI`

其中，`λ_FAC`、`λ_TAEF` 和 `λ_GCTI` 分别对应共享锚点对齐约束、任务证据增强约束和任务关系一致性约束。

## 正文可插入到实验部分的文字

### CMCF Loss 参数设置与敏感性分析

为分析 CMCF Loss 中协同约束参数对识别性能的影响，本文在三模态完整输入设置下进行了单因素敏感性实验。实验采用 5 个随机种子，在保持其余训练参数不变的条件下，分别对 `λ_FAC`、`λ_TAEF` 和 `λ_GCTI` 进行逐一搜索，并以验证集综合得分均值作为比较指标。结果如表 X 所示。

从表 X 可以看出，`λ_TAEF` 对模型性能影响最为明显，当 `λ_TAEF` 从 `0.01` 增大到 `0.10` 时，验证集综合得分由 `0.7102±0.0061` 提升至 `0.7168±0.0030`，说明适度增强任务证据协同有助于提升不同模态间的判别互补性。相比之下，`λ_GCTI` 的变化对整体结果影响相对平缓，在 `0.00~0.10` 范围内综合得分波动不超过 `0.0007`。`λ_FAC` 过小时容易削弱共享锚点对齐作用，过大时又会抑制模态差异信息，因而在中等权重附近能够取得更稳健的表现。综合精度与训练稳定性，本文最终采用 `λ_FAC=0.05`、`λ_TAEF=0.01`、`λ_GCTI=0.01` 作为正式实验设置。

需要说明的是，`α` 由训练集类别分布自适应确定，并非独立可调的单一标量，因此本文在修稿中重点补充其具体取值；`γ` 取 Focal Loss 中常用的 `2.0`，用于平衡易分类样本抑制与难分类样本关注强度。
